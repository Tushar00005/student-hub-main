The website name is : ByteBlogs
ByteBlogs is a student-focused blogging platform where users can explore posts, create their own posts, like and comment on blogs, and share knowledge in a simple and modern interface.

Features
1) Explore blog posts
2) Create and publish posts
3) Like and comment on posts
4) Clean and responsive UI

Tech Stack
1) Frontend: Vite + React
2) Language: TypeScript
3) Styling: Tailwind CSS

Installation & Setup
Follow these steps to run the project locally:
1) Clone the repository
git clone https://github.com/your-username/byteblogs.git
2) Navigate to the project directory
cd byteblogs
3) Install dependencies
npm install
4) Start the development server
npm run dev

Run the Website
After running npm run dev, a localhost URL will appear in the terminal.
Click the link and start exploring ByteBlogs 

Project Purpose
This project is built for students to practice modern frontend development using Vite, TypeScript, React, and Tailwind CSS, while creating a real-world blogging platform.
